# docs

This repo's brain: one markdown file per topic, indexed here. The convention itself is the
`Project docs` section of [`quzzar-workplace`](../skills/quzzar-workplace/SKILL.md).

- [skill-template.md](skill-template.md) covers the `SKILL.md` frontmatter and how to write a
  `description` that triggers reliably instead of misfiring. Copy it when adding a skill.

Installing the skills and how their workflows fit together are covered in the
[root README](../README.md). That's the surface for people *installing* these skills; `docs/`
is for people *changing* them.

- [motion-skills.md](motion-skills.md) covers the vendored motion collection, source revision, licensing, and updates.

- [rust-skills.md](rust-skills.md) covers the bundled Rust rule collection, provenance, local adaptations, and updates.

- [ui-ux-design.md](ui-ux-design.md) covers the image-first design workflow, source research, and approval boundaries.
